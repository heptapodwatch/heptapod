# Crawl checks

`broken_links` and `mixed_content` share one plain-HTTP Spatie crawl per site per 24-hour interval. JavaScript is not executed. Not detected: CSS-referenced resources in inline styles, style blocks or fetched stylesheets (`url()` and `@import`). TODO: Add CSS resource parsing in a separate follow-up. Mixed content uses an accepted fresh artifact or collects through the same path when it is the only enabled check.

Crawl limits and mixed-only defaults come from the broken-links config schema; `config/crawl.php`, merged under `heptapod.crawl`, supplies their declared default values. Pattern lists trim entries and drop blanks through the shared schema boundary; whitelist entries reject whitespace. Resource types use the API spelling `og:image`, mapped to Spatie's OpenGraphImage. The core outbound HTTP seam supplies Spatie's guarded client configuration and enforces wire/decoded byte limits, verified TLS, per-request timeouts and the overall check deadline. Its `untrusted` redirect policy validates and pins every dispatch and hop. The enabled broken-links check supplies crawl settings. Artifacts retain those settings; each evaluation applies the current whitelist and external-link policy. `new_links_only` preserves the imported setting; notifications always report only newly found issues, while severity considers all non-whitelisted issues.

The crawler requires public addresses for third-party links and redirects. Same-host means equal normalized hostname strings, not equal resolved IPs. The configured hostname may use its execution's first resolved private addresses; link-local, known provider metadata endpoints, NAT64 and 6to4 are refused even for that hostname. Each distinct host is resolved once per execution with a deadline-bounded resolver. Every dispatch and redirect is classified again and pinned to that cached numeric set, so DNS changes cannot introduce a new private destination. There is no cross-host private override. A refused link or resource is a Not verifiable finding (`private_target`, "Not checked: private network address"); the rest of the crawl still counts. A refused start page is a Check error. Site crawler headers remain only on the normalised site origin; the core seam removes all caller headers on cross-origin redirects. Same-origin pages alone enter Spatie's queue. Discovered external destinations receive separate guarded status-only checks without site headers, recursive extraction or mixed-content inspection. Same-origin link targets use the `max_pages` bound (default 2,000); same-origin resources and external destinations each have their own status-only bound (`max_status_urls`, default 10,000), within the same execution deadline. The built-in Cloudflare email-obfuscation path `/cdn-cgi/l/email-protection` is ignored on the monitored origin. Findings remove URL userinfo and fragments while retaining queries. The shared core redactor masks configured crawler-header secrets and operator-URL query values in remote/operator text before storing findings, artifacts or identities. Matching is literal, ASCII case-insensitive, longest first, and preserves inserted masks; values shorter than four characters are not redacted. Generated timestamps and fixed codes are unchanged. Whitelist values and findings are compared in the same redacted form. Crawler header settings are never copied into artifacts. Events and evidence contain only bounded finding hashes and counts.

The collection cache is an unpublished external observation protected by a per-site Redis lock. A hidden HMAC of the canonical target URL, keyed with the active Laravel encryption key, distinguishes URL edits without exposing their credentials. Rotating APP_KEY causes one recrawl because the cache identity changes. Bounded page-limited crawls remain comparable. Evaluation normalizes current and accepted evidence with the current core secret redactor before matching or comparing identities. Pruning requires completed internal traversal, an observed root, no page cap, no timeout/deadline exhaustion and no unavailable HTML page. A terminal 404/410 is a finding, not a failure to discover links on other pages. Only then may absent URLs leave scope without per-finding resolution events. Any incomplete traversal retains all unobserved evidence, including unseen descendants. This includes dropped callbacks and unchecked external destinations. Traversal depth is supplied by Spatie's response handler before extraction, independent of `noindex` observer suppression. Mixed-content availability tracks successfully observed HTML per page; unavailable pages retain prior findings. An unavailable root yields no mixed observation, leaving its state and baseline unchanged, while broken-link HTTP statuses remain observable. Collection time limits and interruptions yield no accepted observation. Recorder acceptance publishes run-specific findings. Retention keeps each check's accepted baseline; rejected attempts cannot publish findings. Comparisons exceeding 25,000 rows or references keep bounded current metrics and an EN/DE comparison-limit diagnostic, emit no comparison events and leave the baseline unchanged. The result cannot improve past retained baseline findings, so overflow cannot close their incident.

Run the addon checks with `docker compose exec app vendor/bin/pest addons/crawl/tests --compact`.

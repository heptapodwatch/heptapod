# Security policy

Report vulnerabilities privately at https://github.com/heptapodwatch/heptapod/security/advisories/new (GitHub Security Advisories). Do not use public issues or pull requests for undisclosed vulnerabilities.

Include the affected version, deployment mode, impact and minimal reproduction steps. Use synthetic data and redact tokens, passwords and customer information. Do not probe instances you do not control.

If private reporting is unavailable, ask the maintainers to enable it without publishing vulnerability details.

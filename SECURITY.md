# Security policy

Report vulnerabilities privately at https://github.com/heptapodwatch/heptapod/security/advisories/new (GitHub Security Advisories) or by email to security@heptapod.watch. Do not use public issues or pull requests for undisclosed vulnerabilities.

Include the affected version, deployment mode, impact and minimal reproduction steps. Use synthetic data and redact tokens, passwords and customer information. Do not probe instances you do not control.
